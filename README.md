### ⭐ Proyecto destacado

#### [Instituto Códice: sistema de asistencia y notas](https://github.com/Pazvzv24/InstitutoCodice)

Aplicación de escritorio en **C# .NET 8 y SQL Server** que nació como proyecto académico y evolucionó a un sistema con seguridad desde el diseño.

<img src="https://raw.githubusercontent.com/Pazvzv24/InstitutoCodice/master/docs/img/demo.gif" alt="Demostración de Instituto Códice" width="700">

- **Autenticación segura:** PBKDF2-SHA256 con sal, política de contraseñas y bloqueo de cuenta.
- **Bitácora de auditoría inmutable:** cada cambio de datos queda registrado en la misma transacción.
- **Mínimo privilegio** en la base de datos y secretos fuera del código.
- **Ley 21.719:** aviso de privacidad, derechos del titular, bloqueo del tratamiento y minimización de datos.
- **Calidad:** 46 pruebas automáticas, CI con GitHub Actions, CodeQL y Dependabot.
- **Modelo de amenazas STRIDE** y release descargable con verificación SHA-256.
